Your first stack

In five minutes: a Postgres your app reaches by name, which starts when your app connects and sleeps when it stops.

1. Declare it

In your project's folder, run doze init. It reads what your project uses and writes doze.hcl. Here the project is Larder, the example grocer:

doze.hcl
stack = "larder"

module postgres "postgres" {
  version = 18
}

2. Connect

Bring the stack up, then connect as your app would. Postgres was asleep; the connection wakes it.

Terminal
$ doze up
○ postgres  asleep, wakes on a connection
$ psql postgres://postgres@postgres.larder.doze/postgres -c 'select 1'
● postgres  awake in [time]

Your app reads DATABASE_URL? doze run -- go run ./services/catalog sets it for you, and stops the stack when your command ends.

3. Walk away

After two minutes with no connection, postgres goes back to sleep. Its data stays in ~/.doze. Change the time with sleep = "10m", or keep it on with sleep = "never".

A bigger stack

Larder itself runs nine services in Go, Python and TypeScript on postgres, redis, kafka, aws and mailpit, from one file. Clone it to see every piece of doze.hcl in use.

Terminal
$ git clone https://github.com/doze-dev/doze-examples
$ cd doze-examples/larder && doze up
