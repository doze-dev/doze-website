Postgres extensions · 16

Write a name. doze fetches the build for your Postgres and your machine.

Each extension is built per version, per Postgres major and per platform, checked against its digest and pinned in doze.lock, like the engine itself. Ones that must be preloaded are added to shared_preload_libraries for you.

doze.hcl
module postgres "postgres" {
  version    = 17
  extensions = ["vector", "pg_cron"]
}

module postgres "metrics" {
  version = 17
  extension "timescaledb" { version = "2.31" } # pinned
}
