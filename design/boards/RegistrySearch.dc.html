redis isn't a module and isn't one of the 9 bring-your-own tools, so it isn't counted above. You can still run it as a service.
What doze add redis writes today: nothing is known, so a download to fill in.
doze.hcl, a placeholder to fill in
service "redis" {
  # fetched once, pinned in doze.lock by its checksum, and run from the archive
  download = "https://example.com/redis-darwin-arm64.tar.gz" # fill this in
  run      = "./redis --port $PORT"
}
Or write it by hand to run the redis-server you installed:
doze.hcl, by hand
service "redis" {
  run  = "redis-server --bind $HOST --port $PORT --dir $DATA"
  port = 6379
}

doze still gives it a .doze name, a port, sleep and wake, and logs. Most apps never notice the swap to Valkey, which is signed and pinned. How bring-your-own works
