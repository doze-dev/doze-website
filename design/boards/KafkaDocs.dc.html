Connect your client

Every client below is tested against doze Kafka in CI. Set bootstrap.servers to the broker's name; nothing else changes.

Go, with franz-go

Larder's orders service reads payment results like this:

Go
cl, err := kgo.NewClient(
    kgo.SeedBrokers("kafka.larder.doze:9092"),
    kgo.ConsumerGroup("orders"),
    kgo.ConsumeTopics("payments.settled", "payments.failed"),
)

Python, with confluent-kafka

Python
from confluent_kafka import Consumer

c = Consumer({
    "bootstrap.servers": "kafka.larder.doze:9092",
    "group.id": "fulfilment",
})
c.subscribe(["payments.settled"])

Inside a doze stack, don't write the address: KAFKA_BROKERS = module.kafka.address in doze.hcl hands it to every service.

With a schema registry

The registry is built in and Confluent-compatible. Stock serializers need one setting: schema.registry.url=http://schema.larder.doze.

From a container, the name does not resolve. Use --listen and see Endpoints.
