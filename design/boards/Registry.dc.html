The registry

Every engine doze can run. Signed, pinned, one line each.

Modules are the plugins that run Postgres, Valkey, Kafka and the rest. Add one to doze.hcl and doze fetches it for your machine, checks it, and pins it in doze.lock, so the next fetch is the same bytes.

Signed by one keyEvery file and the index are signed with one ed25519 key; its public half is compiled into doze. Pinned in doze.lockVersion and sha256 per platform. Only doze modules upgrade moves a pin. Verified on every fetchA file that doesn't match its signature and hash is not run. How it works →
