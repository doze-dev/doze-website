It's a name, not a port

Each broker answers on its own loopback address with a name, so nothing on your network can reach it and two projects can both use 9092. Stop it with Ctrl-C: topics, messages and committed offsets are all there next time.

$ cd ~/code/larder && doze-kafka
  broker   kafka.larder.doze:9092
  console  http://kafka.larder.doze

$ kcat -b kafka.larder.doze:9092 -t orders.placed -P
$ kcat -b kafka.larder.doze:9092 -t orders.placed -C -e
{"order_id": "[id]", "total": "[amount]"}
Inside a doze stack

The topics are the contracts.

In Larder, the example grocer, services in Go, Python and TypeScript talk through four topics, declared in doze.hcl rather than created by whichever client writes first. franz-go, confluent-kafka and KafkaJS, all on one broker.

# doze.hcl, from Larder
module kafka "kafka" {
  version            = 4
  port               = 9092
  auto_create_topics = false

  topic "users.signed-up"  { partitions = 3 }
  topic "orders.placed"    { partitions = 3 }
  topic "payments.settled" { partitions = 3 }
  topic "payments.failed"  { partitions = 3 }
}

What you get

Wire protocol Kafka 1–4

One binary speaks Kafka 1 to 4; pick which with --kafka-version (default 4).

Consumer groups

The classic protocol and KIP-848, chosen by the client.

A schema registry, built in

Confluent-compatible: Avro, JSON Schema and Protobuf. Stock serializers need only schema.registry.url.

A console that explains

Topics, messages, lag, and why a group keeps rebalancing, with the Kafka error names.

Transactions, SASL and TLS

Transactional producers and read-committed consumers. SASL/PLAIN, SCRAM-256/512 and TLS when you want them.

Durable

With acks=all an acknowledged write is fsynced before the ack.

Flat memory

Idle memory stays in the tens of MB however much data sits on disk.

Embeddable in Go tests

server.New(...) starts a broker on a free port, nothing to clean up.

What it isn't, on purpose

A single node for development, not production. Anything a client can't observe through the socket is left out.

  • No replication, ISR or controller quorum
  • No byte-for-byte on-disk segment compatibility
  • No tiered storage or quotas
