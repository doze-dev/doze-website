How it is verified

Three separate proofs that this namespace belongs to the people who make doze.

Key compiled into doze

The namespace key is a constant in doze's own source. Every doze binary checks against it.

in place

Source in the doze-dev GitHub org

Modules build from doze-modules, doze AWS and doze Kafka; signing runs in doze-registry.
